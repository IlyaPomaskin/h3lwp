## Requirements

The app includes no game content. It needs files from your own copy of Heroes of Might and Magic III: Shadow of Death or Complete Edition (for example, the [GOG](https://www.gog.com/game/heroes_of_might_and_magic_3_complete_edition) version). Horn of the Abyss support is optional and uses the official installer from [h3hota.com](https://h3hota.com/en/download).
